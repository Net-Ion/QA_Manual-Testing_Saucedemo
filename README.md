# 🧪 SauceDemo QA Testing Project

## 📌 About the Project

This project is a **manual QA testing project** created to practice the software testing process on the SauceDemo sample e-commerce application.

The project covers the complete basic manual testing workflow, starting from identifying functional requirements and creating test cases to executing them, reporting defects, maintaining an RTM, and preparing test execution and summary reports.

The main application modules tested are:

- 🔐 Login
- 🛍️ Inventory / Products
- 🛒 Your Cart
- 💳 Checkout

The purpose of this project is to demonstrate practical understanding of **manual software testing, test case design, test execution, defect reporting, requirement traceability, and QA documentation**.

# 🎯 Project Objectives

The main objectives of this project are:

- Understand functional requirements of the application
- Identify important test scenarios
- Create structured test cases
- Execute test cases manually
- Perform positive and negative testing
- Identify and document defects
- Understand severity and priority
- Maintain requirement traceability
- Prepare test execution reports
- Prepare a final test summary
- Organize QA documentation for a complete testing cycle
